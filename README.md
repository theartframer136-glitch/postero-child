# Contact sheets

Product pictures drawn out of the live catalogue so they can be held
against the pages of TheARTFramer Master Brochure.

APPLIED.txt is the art-code apply step's own report: what it
changed, cleared, refused as a clash, or found already correct.

RENUMBERED.txt is the pass that restates every art code in the
numbering the book prints now — RK 01 is RK - 0101 — and lists
the products it left alone because their code names no page of
the book.

This branch is a delivery channel, not history. It is force-pushed on
every deploy and holds only the newest sheets. Delete it when the
art-code audit is done.
